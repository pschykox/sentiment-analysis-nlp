# Sentiment Analysis with NLP
🥇1 место в ХАКАТОНЕ от Хакатоны.рус🥇
Это мой проект по анализу тональности текстов. Идея пришла когда я читал отзывы на фильмы и подумал - а можно ли научить компьютер понимать эмоции в тексте? Решил попробовать сделать это с помощью нейронных сетей.

## Что делает проект

Программа анализирует текст (например, отзыв на фильм или товар) и определяет его тональность - позитивный он или негативный. Использую для этого LSTM нейронную сеть, которая умеет "запоминать" контекст слов в предложении.

## Как это работает

1. **Обработка текста** - текст разбивается на слова и преобразуется в числовые последовательности
2. **Embedding слой** - каждое слово превращается в вектор, который содержит его "смысл"
3. **LSTM слои** - анализируют последовательность слов, учитывая контекст
4. **Классификация** - на выходе получаем вероятность того, что текст позитивный или негативный

## Технологии

- **Python 3.8+** - основной язык
- **TensorFlow/Keras** - для создания и обучения нейросети
- **NumPy** - работа с массивами данных
- **NLTK** - обработка естественного языка

## Датасет

Для обучения использовал датасет IMDB Movie Reviews - это 50,000 отзывов на фильмы (25k для обучения, 25k для тестирования). Отзывы уже размечены на положительные и отрицательные, что идеально подходит для обучения модели.

## Архитектура модели

```
Embedding Layer (10000 слов -> 128 измерений)
    ↓
Bidirectional LSTM (64 units)
    ↓
Bidirectional LSTM (32 units)
    ↓
Dense Layer (64 neurons, ReLU)
    ↓
Dropout (0.5)
    ↓
Output Layer (1 neuron, Sigmoid)
```

## Результаты

После 10 эпох обучения модель показывает:
- **Точность на тестовых данных: ~87%**
- **Loss: ~0.35**

Не идеально, но для первого проекта в NLP результат неплохой. Планирую улучшить модель, добавив attention механизм.

## Установка и запуск

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Обучение модели
```bash
python train_sentiment.py
```
Обучение занимает примерно 20-30 минут на обычном ноутбуке.

### Анализ своего текста
```bash
python analyze.py --text "This movie was absolutely amazing!"
```

## Примеры работы

**Позитивный отзыв:**
```
Текст: "This movie was absolutely amazing! Great acting and plot."
```

**Негативный отзыв:**

```
Текст: "The movie was okay, nothing special."

Уверенность: 54%
```

## Что я узнал

- Как работают рекуррентные нейронные сети (LSTM)
- Как обрабатывать текстовые данные для машинного обучения
- Важность правильной предобработки данных
- Bidirectional LSTM работает лучше чем обычный LSTM
- Dropout помогает избежать переобучения
